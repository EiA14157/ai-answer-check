# AI 오답 찾기

AI 답변처럼 보이는 세 문장 중 **틀린 문장 하나**를 찾는 한국어 퀴즈입니다. 10문제에 숫자 계산, 자료 읽기, 조건 추론을 담았습니다. 선택 직후 해설을 볼 수 있습니다.

실제 AI가 쓴 글인지 판별하는 도구가 아닙니다. 문제와 해설은 이 게임용으로 작성한 예시이며, 정답은 각 문제에 제시된 정보만으로 구할 수 있습니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 네트워크 연결, 서버, 로그인, 설치, 빌드가 필요 없습니다. 입력값을 전송하거나 브라우저에 저장하지 않습니다.

GitHub Pages에서는 저장소의 기본 브랜치 루트를 배포 소스로 지정할 수 있습니다.
